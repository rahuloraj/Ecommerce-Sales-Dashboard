# E-Commerce Sales Dashboard (Data Analytics)

**Summary**
A simple analytics dashboard that ingests sales CSV data, aggregates KPIs (revenue, orders, AOV), and produces charts and a static HTML dashboard generated with Plotly.

**What's included**
- `notebooks/analysis.ipynb` - exploratory analysis (placeholder)
- `app/dashboard.py` - script to generate HTML dashboard with Plotly
- `data/sample_sales.csv` - small sample dataset (synthetic)
- `requirements.txt` - Python dependencies
- `README.md` - this file

**How to run**
1. Create a Python virtual environment: `python -m venv venv && source venv/bin/activate`
2. Install: `pip install -r requirements.txt`
3. Run dashboard generator: `python app/dashboard.py`
4. Open `dist/dashboard.html` in your browser.

**Resume blurb (one-liner)**
Built an interactive sales analytics dashboard using Python and Plotly to visualize revenue, product performance and trends.
